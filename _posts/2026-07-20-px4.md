# Options

```text
# Set simulation model
PX4_SIM_MODEL=gz_x500_mono_cam
PX4_SIM_MODEL=gz_x500_depth
PX4_SIM_MODEL=gz_x500_gimbal

# Set simulation world (Gazebo only)
PX4_GZ_WORLD=default
PX4_GZ_WORLD=windy
PX4_GZ_WORLD=baylands
PX4_GZ_WORLD=runway

# Set simulation speed factor
PX4_SIM_SPEED_FACTOR=2
PX4_SIM_SPEED_FACTOR=0.5

# Set stream destination (when using VM and capture to host address)
PX4_VIDEO_HOST_IP=192.168.122.1

# Disable Gazebo GUI
HEADLESS=1
```

# Run (pre-builds)

* Install dependencies:
```shell
sudo usermod -a -G dialout $USER
sudo apt-get remove modemmanager -y
sudo apt install gstreamer1.0-plugins-bad gstreamer1.0-libav gstreamer1.0-gl -y
sudo apt install libfuse2 -y
sudo apt install libxcb-xinerama0 libxkbcommon-x11-0 libxcb-cursor-dev -y
```
* Logout and login again to enable the change to user permissions

* Run `px4-sitl-gazebo` docker:

```bash
$ docker run -it \
   --rm \
   --network host \
   -e PX4_SIM_MODEL=sihsim_quadx \
   px4io/px4-sitl:latest
# Press Esc to quit from follow mode
```

OR

* Run `px4-sitl-gazebo` docker:
```bash
$ xhost +local:docker
$ docker run -it \
   --gpus all \
   --rm \
   --network host \
   -e PX4_SIM_MODEL=gz_x500_depth \
   -e DISPLAY=$DISPLAY \
   -v /tmp/.X11-unix:/tmp/.X11-unix \
   px4io/px4-sitl-gazebo:latest
# Press Esc to quit from follow mode
```

Note: In order to disable Gazebo GUI add `-e HEADLESS=1`

# Run (with compilation)

Install dependencies:
```bash
$ sudo apt install -y git
$ mkdir -p tools/PX4 && cd tools/PX4
$ git clone https://github.com/PX4/PX4-Autopilot.git --recursive
$ cd PX4-Autopilot
$ bash ./PX4-Autopilot/Tools/setup/ubuntu.sh
$ sudo reboot
```

```bash
$ cd tools/PX4/PX4-Autopilot
$ make clean
$ make distclean
$ git checkout -b v1.17.0 v1.17.0
$ make submodulesclean
```

Install and run QGroundControl:
```bash
$ mkdir -p tools/QGC
$ cd tools/QGC
$ wget https://d176tv9ibo4jno.cloudfront.net/builds/master/QGroundControl-x86_64.AppImage
$ ./QGroundControl-x86_64.AppImage
```

Run (without GUI):
```bash
$ HEADLESS=1 make px4_sitl gz_x500_depth
```


# Commands

List of the useful SITL command:

* Takeoff the drone:
```shell
pxh> commander status
INFO  [commander] Disarmed
INFO  [commander] prearm safety: Off
INFO  [commander] navigation mode: Hold
INFO  [commander] user intended navigation mode: Hold
INFO  [commander] in failsafe: no
pxh> commander arm -f
px4> commander takeoff
```

* Land the drone:
```shell
px4> commander land
```

# Other

## Persist flight logs on the host

```bash
$ mkdir -p ./px4-logs
$ docker run -it \
   --rm \
   --network host \
   -v $(pwd)/px4-logs:/root/.local/share/px4/rootfs/log \
   px4io/px4-sitl-gazebo:latest
```

## List published topics

Run onboard command:
```bash
$ gz topic -l
```

## Read pushed topic

```bash
$ gz topic -e -t /world/default/model/x500_depth_0/link/camera_link/sensor/camera_imu/imu
```

## Capture RTSP camera stream

```bash
gst-launch-1.0 -v \
  udpsrc port=5600 caps="application/x-rtp, payload=96, encoding-name=H264" ! \
  rtph264depay ! \
  avdec_h264 ! \
  videoconvert ! \
  autovideosink
```
